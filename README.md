# Слой — coffee studio concept

Адаптивный сайт вымышленной кофе-студии. Полностью новая айдентика, монохромный дизайн по предоставленным референсам, новое меню и сгенерированные предметные фотографии. Отзывы — явно обозначенные демонстрационные истории. Данных и ссылок действующей кофейни в публичных материалах нет.

## Запуск

Node.js 20.9+:

```sh
npm install
npm run dev
```

Адрес: http://localhost:3000. Production: `npm run build`, затем `npm start`.

## Возможности

- Hero с параллаксом фото, типографики и стеклянной подписи.
- Самостоятельный LiquidGlass: backdrop blur, SVG-рефракция в поддерживающих её браузерах, светлые объёмные края и реакция блика на курсор.
- Движение предметных изображений при скролле, плавные появления и reduced motion.
- Категории меню, поиск по названию и вкусу, раскрытие всех позиций.
- Избранное с локальным сохранением и отдельным фильтром.
- Карточка состава и аллергенов в нативном dialog.
- Переключаемая история выпечки и подбор ритуала по настроению.
- Мобильная навигация, видимый фокус, поддержка клавиатуры.
- Новый логотип «Слой», favicon, социальная обложка.
- Нет градиентов и внешних UI-библиотек.

## Архитектура

Next.js / React / strict TypeScript / SCSS Modules. Слои: app → views → widgets → features → entities → shared. Прямые импорты без barrel-файлов. Основная страница компонуется в views/home.

`public/assets/` содержит только новые материалы концепта. В `src/entities/menu/model/menu.ts` находятся придуманные позиции, в `src/entities/review/model/reviews.ts` — вымышленные отзывы. На позициях без изображения указано «нет фото».

`NEXT_PUBLIC_DEMO_URL` из `.env.example` можно задать адресом размещения концепта. Индексация всегда отключена: проект не выдаёт вымышленное место за действующий бизнес. Геокоординаты, телефон, внешние карты, рейтинг реального заведения и ссылки на доставку отсутствуют. JSON-LD описывает CreativeWork.

Скилы: Emil Kowalski, Vercel React Best Practices, imagegen. Новые фотографии созданы imagegen, без исходных фотографий реальных заведений. Подробности дизайна — в DESIGN.md.

По ранее заданной просьбе пользователя сборка, тесты и визуальная проверка после изменений не запускались.
