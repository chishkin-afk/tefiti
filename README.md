# Тефити

Адаптивный сайт кофейни на Красной, 98 в Краснодаре. Next.js 16, React 19, TypeScript, SCSS Modules. Проект целиком находится в этой папке; материалы исходной подборки скопированы в `public/assets/`.

## Запуск

Нужен Node.js 20.9+.

```sh
npm install
npm run dev
```

Открыть `http://localhost:3000`.

Для production:

```sh
npm run build
npm start
```

## Что сделано

- Hero с разной скоростью движения фотографии интерьера, десерта и ракушки при скролле.
- Однократные мягкие появления блоков, состояния нажатия, поддержка `prefers-reduced-motion`.
- Мобильная навигация через нативный dialog, переход к содержимому, видимый фокус.
- Меню: все 52 позиции Яндекс Еды, категории, поиск, показ остальных позиций и оригинальные фотографии бумажного меню.
- У пяти позиций доставки отсутствуют собственные фотографии. На сайте явно написано «нет фото»; общие заглушки не используются.
- Три реальных отзыва: помеченные пересказы с авторами, датами и ссылками на полные отзывы.
- Контакты, телефон, Telegram, маршрут и встроенная карта Яндекса перед футером.
- Логотип-ракушка восстановлен в SVG; также подготовлены PNG 4096×4096, прозрачная версия и favicon. Компонент `Shell` использует тот же рисунок.
- Локальные шрифты Lora и Golos Text с кириллицей; лицензии в `public/fonts/`.
- Только однотонные заливки, без градиентов.

## Архитектура

Следует `arch-rules.md`:

```text
src/app/                  маршруты, metadata, robots, sitemap
src/views/home/           композиция страницы
src/widgets/              header, hero, about, menu, dessert-story, reviews, contacts, footer
src/features/browse-menu/ фильтрация и поиск меню
src/entities/             модели меню и отзывов, карточка позиции
src/shared/               UI, конфигурация, SEO, базовые стили
```

Прямые импорты, алиас `@/*`, SCSS Modules, strict TypeScript. Клиентские границы находятся у интерактивных компонентов; контент страницы рендерится на сервере.

## Перед размещением на домене

Создать `.env.local` по образцу `.env.example` и задать **реальный** адрес:

```dotenv
NEXT_PUBLIC_SITE_URL=https://ваш-домен.ru
```

Значение используется при сборке. До настройки домена индексация отключена, чтобы не индексировать тестовую копию. При заданном адресе автоматически включаются robots, canonical, sitemap и абсолютные Open Graph URL.

SEO: серверный HTML, один H1, смысловая структура заголовков, русский язык, метаданные, Open Graph, социальная обложка, JSON-LD CafeOrCoffeeShop с адресом, телефоном, геокоординатами и временем работы. Изображения оптимизируются Next Image; первая фотография получает preload, остальные загружаются лениво, как и карта. Шрифты не зависят от внешнего CDN.

После публикации добавить домен и sitemap в Яндекс Вебмастер и Google Search Console, указать сайт в карточке организации и подтвердить актуальность часов работы, телефона, ассортимента и цен. Настройка сайта не гарантирует первое место в выдаче.

## Источники контента

`public/assets/sources.json` — источники исходных изображений. `public/assets/menu/` — каталоги и цены; `public/assets/reviews/` — авторы и оригинальные ссылки. На сайте приведены цены доставки; они могут отличаться от цен в кофейне. Фотографии бумажного меню отражают разные периоды.

## Скиллы и дизайн

Применены локальные Emil Kowalski и Vercel React Best Practices, а также официальный [Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md). Направление и палитра описаны в `DESIGN.md`.

По просьбе пользователя после написания кода не запускались сборка, typecheck, автоматические тесты и визуальная проверка.
